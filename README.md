# Винная подборка

Приложение к ДЗ-3. Python 3.12. Проверено с версиями из requirements.txt.
Модель — StandardScaler + LogisticRegression; порог выбран на валидации по F1.
Текущая модель сохранена с scikit-learn 1.8.0 — эта же версия указана в зависимостях.
Код и анализ подготовлены с помощью OpenAI Codex.

## Локальный запуск

Откройте терминал в папке wine_app и выполните:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Linux/macOS среда активируется командой `source .venv/bin/activate`.
Если среда уже создана, повторите `python -m pip install -r requirements.txt`, чтобы обновить библиотеки.
Модель загружается из model.joblib рядом с app.py; переобучение в приложении не выполняется.
Файл test.csv нужен только для демонстрации метрик и диапазонов полей.

## Вкладки

- Одно вино: 12 лабораторных признаков и решение модели.
- Модельные метрики: матрица ошибок, precision/recall/F1 и точки текущего порога на ROC/PR.
- Пакетное предсказание: CSV, проверка столбцов, скачивание результатов и пример входного файла.
- Что выучила модель: стандартизированные коэффициенты и их интерпретация.

Порог в сайдбаре общий для всех вкладок. Увеличение порога сокращает подборку и обычно повышает
precision ценой recall. Порог не гарантирует определённый recall на новых данных.

## Кэширование

`st.cache_resource` хранит один объект модели на сервер, не копируя его при каждом запросе.
`st.cache_data` хранит таблицы и вероятности, возвращая безопасные копии данных.
Аргумент `_model` исключён из хеширования; тестовая таблица участвует в ключе кэша.
При движении слайдера вероятности test повторно не вычисляются, меняются только метки.
Время изменения файлов входит в ключ кэша: после повторного сохранения модели или test
приложение загрузит новые данные при следующем перезапуске скрипта.
Без декоратора `joblib.load` снова читал бы модель с диска при каждом взаимодействии.

## Streamlit Community Cloud

1. Поместите эту папку в свой GitHub-репозиторий вместе с model.joblib, config.json и test.csv.
2. В https://share.streamlit.io/ выберите Create app, репозиторий и ветку.
3. Укажите путь к приложению: `app.py`, если содержимое wine_app загружено прямо в корень репозитория;
   `wine_app/app.py`, если в корне находится сама папка; или `homework/hw_3/wine_app/app.py` для структуры учебного репозитория.
4. В Advanced settings выберите Python 3.12 и нажмите Deploy.
5. Скопируйте выданный публичный URL в последнюю ячейку ноутбука.

Документация: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app
Приложение готово к локальному запуску. После публикации добавьте сюда ссылку на Streamlit Community Cloud.
